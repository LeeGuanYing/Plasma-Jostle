截至 2026/9/28，目前《Plasma Jostle》的開發狀態可以整理為以下進度。以下以目前 GitHub LeeGuanYing/Plasma-Jostle 的 main 分支為準，而不是沿用舊的 Pokemon-Jason Repo。

目前整體狀態

目前專案已經從單純的劇情／概念階段進入 Unity 遊戲原型與核心系統建立階段。

目前最新 commit 為 2026/9/28 的 9.28。相較前一個 9.27 版本，最新版本主要新增了 PJ 實體識別與 Registry 系統，包含 Persistent ID、Runtime ID，以及 Persistent/Runtime Entity Registry。Plasma-Jostle GitHub Repository

1. Unity 專案基礎

目前 Repo 已具備完整的 Unity 專案結構，包括：

Assets
ProjectSettings
Unity Input System
URP 相關設定
Unity Scene
PJ 專用程式碼架構
生物、玩家、核心系統等程式分類

目前目標 Unity 版本為：

Unity 6000.6.0f1

專案本身已不是空白 Unity 專案，而是已經建立基本遊戲架構。

2. 玩家系統：已有第一版 Framework

目前已經完成第一版 第一人稱 Player Framework。

現有 Player 程式包括：

PlayerController
PlayerCamera
PlayerInteractor

並使用既有的 Unity Input System Player Map。

目前定義的玩家操作包含：

移動 Move
視角 Look
攻擊 Attack
互動 Interact
蹲下 Crouch
跳躍 Jump
前後切換等操作
Sprint

Player Framework 的設計目前已經包含：

第一人稱移動
滑鼠視角
跳躍
蹲下
Interact Raycast
游標鎖定／解鎖

而且這一部分特別採用 Unity Editor Builder 產生測試 Prefab 與 Scene，而不是直接手寫 Unity YAML。

不過這裡有一個明確限制：

目前尚未在 Unity Editor 中完成最終 Compile / Runtime 驗證。

Repo 自己的 README_PlayerFramework.txt 也明確記錄 Unity Editor 不存在於目前的開發環境，因此最後驗證仍需要在 Unity 6000.6.0f1 中進行。

3. 生物系統：已建立基礎架構

目前 Creatures 已經存在基本程式：

Creature
CreatureAI
CreatureData
CreatureHealth
CreatureSpawner

因此目前不是只有玩家，而是已經開始建立：

玩家 → 生物 → AI → HP → Spawn

這一層的遊戲邏輯架構。

但目前從 Repo 可以確認的是基礎程式框架已建立，並不能據此確認完整的生物戰鬥、動畫、行為樹或最終生物內容已完成。

4. PJ 核心系統：正在形成正式架構

目前核心程式已經有：

PJEntity
PJEntityManager
PJGame

而 9/28 最新版本又加入了一整組 Entity Identity / Registry 系統：

PersistentId
PersistentIdentity
RuntimeId
PJPersistentEntityRegistry
PJRuntimeEntityRegistry
EntityRegistrationResult
EntityUnregistrationResult

這代表目前開發開始處理一個很重要的問題：

遊戲中的 PJ 實體如何被可靠地識別、註冊，以及區分「持久存在的 ID」與「本次執行期間的 Runtime ID」。

這是 9/28 相較 9/27 最明確的程式架構進展。

5. 劇情：核心設定已確立，但尚未進入完整劇情實作

目前 Repo 中已經有正式的 Storyline.txt。

目前確定的故事框架是：

世界政府特殊事件研究部隊 → 前幾支探險隊全部失聯 → 新六人探險隊進入異世界 → 玩家為通訊人員 → 任務是找出前幾支探險隊的下落。

隨著調查進行，問題逐漸從：

前幾支探險隊去了哪裡？

變成：

前幾支探險隊為什麼失蹤？

最後再進一步變成：

前幾支探險隊在失蹤前到底發現了什麼？

此外，已經確定存在一條獨立的隱藏暗線，其線索會分散在對話、環境、紀錄與通訊等內容中，最後與主線產生交集。

因此目前劇情屬於：

世界觀與主線骨架已確立 → 細節劇情尚未完整製作。

6. 地圖與地形：目前已進入地形資料研究階段

目前 Repo 已經存在：

map_2D.jpeg
推估版_10km_DEM_與地圖配準.tif

而近期開發也已經開始針對 10 × 10 km 等高線／DEM 地形進行分析。

因此目前地圖工作已經不是單純「畫一張地圖」，而是開始建立：

2D 地圖 → 等高線 → DEM → 地形高度 → 河流／地形方向 → 未來 3D 地形

這部分目前仍屬於地形資料分析與設計階段，尚不能確認已經完成可直接遊玩的 3D Terrain。

目前可以用一句話描述的開發進度

Plasma Jostle 目前已完成 Unity 專案基礎、第一版第一人稱玩家 Framework、生物與 PJ 核心程式的初步架構，並於 9/28 開始建立正式的 PJ Entity Identity / Registry 系統；劇情主線與世界觀已形成正式文件，10×10 km 地形資料也已進入 DEM／等高線分析階段，但完整遊戲場景、最終地形、生物內容、戰鬥系統、劇情事件與整體遊戲流程尚未完成。
